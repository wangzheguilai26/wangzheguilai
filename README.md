## 📖 项目简介 (Introduction)

**“王者归来 (WZGL)”** 是一个基于波场 (TRON) 主网发行的标准 TRC-20 代币。

与传统的中心化代币不同，WZGL 采用了**极致去中心化**的设计理念：
- **没有 Owner（管理员）**：部署即放弃权限。
- **没有 Mint（增发）**：总量恒定 10 亿枚，永久锁死。
- **没有黑名单**：任何人之间可以完全自由、无许可地转账。

- **🛡️ 极致安全**：底层基于 OpenZeppelin 标准实现，彻底杜绝重入攻击和溢出漏洞。
